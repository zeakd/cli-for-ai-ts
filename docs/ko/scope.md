# 구현 지원 범위

[English](../scope.md) · 한국어 · [README](../../README.ko.md)

이 문서는 코드와 함께 관리하는 구현을 설명합니다. [가이드](https://github.com/zeakd/cli-for-ai-guide)는 설계 원칙을 다루며 아직 구현하지 않은 내용도 있습니다. `main`은 현재 소스를 설명하며 설치한 패키지 버전은 다를 수 있습니다.

## 지원하는 동작

| 영역 | 제공하는 동작 |
| --- | --- |
| 탐색 | 혼합 깊이 명령 트리; 인자 없는 애플리케이션·그룹은 도움말과 동일; 생성된 예제 호출과 설명 |
| 입력 | 모르는 입력·초과 입력 거부; 스칼라·반복 값, 기본값, 직접 제공 여부를 구분하는 값·입력 간 제약, `--` 뒤 전달 인자 |
| 작성 | 인라인 선언, 리터럴 보존 헬퍼, `dynamicCommand`를 통한 동적 선언 |
| Stdin | 텍스트·JSON, 컨텍스트 전 형태 파싱, 스칼라 일치 조건으로 읽기 선택 |
| 일반 결과 | JSON 기본값, 명시적인 사람용 렌더링, completed/accepted/failed, 선택적 출력 파서와 필드 설명 |
| 페이로드 | JSONL 객체와 LF/NUL 텍스트 레코드, 백프레셔, 레코드 한도, 부분 실패 보고, 선언한 수신 측 종료 정책 |
| 실행 | 컨텍스트 주입·정리, 협조적 신호 처리, Node runner가 소유한 쓰기의 flush |
| 조회 | 프로그램용 애플리케이션 스키마와 스키마 lint |
| 어댑터 | 핸들러별 neverthrow와 제한적인 Effect 지원 |
| 검증 | 타입 검사, 주입된 실행, 실제 프로세스, 빌드 패키지 소비자 |

## 경계

작업 스킬, 구조화된 결과 액션과 힌트, 아티팩트 관리, 바이너리 페이로드, 확장된 부분 작업·결과 미확정 상태는 구현하지 않았습니다. 페이로드 진행 상황 보고가 그런 작업 상태를 구현하는 것은 아닙니다. 기계가 읽는 조회·변경 분류도 제공하지 않으므로 명령 설명에 효과를 명시해야 합니다.

입력은 [문서화된 문법](inputs.md#인자-문법)을 사용합니다. 공유 플래그와 설정 우선순위는 애플리케이션이 맡습니다. 옵션 관계는 `constraints`로 표현하며 전용 배타·의존 관계 헬퍼는 없습니다. 일반 제약은 프레임워크 표현 플래그를 읽을 수 없습니다. 페이로드는 `readerClose: "require-full"`이 기본이며 검색용 명령은 조기 종료를 명시적으로 허용할 수 있습니다. [페이로드](payloads.md#수신-측-종료-정책-선택)를 참고합니다.

선택된 stdin은 전부 버퍼링합니다. `execute`도 페이로드 출력을 수집하므로 점진적인 출력에는 `executeTo`나 Node runner를 사용합니다. 레코드 바이트 한도는 소스·파서·직렬화의 할당량을 제한하지 않습니다. 취소에는 협조가 필요합니다. 이러한 한계와 부분 쓰기 동작은 [페이로드](payloads.md)에서 설명합니다.

스키마와 필드 설명은 출력을 기술하며 파서나 실제 데이터와의 일치를 증명하지 않습니다. 작업 흐름 설명은 작성자가 관리하는 내용입니다. 생성된 검사만으로 확인할 수 없는 부분은 [테스트 방식](testing.md)에서 다룹니다.

Effect는 서비스가 제공된 소스와 기본 런타임을 요구합니다. 어댑터는 페이로드 핸들러를 감싸지 않습니다. 정확한 한계는 [어댑터](adapters.md)를 참고합니다.

## 런타임과 배포

Node 24 이상과 컴파일된 `dist` exports를 사용합니다. TypeScript 소비자에는 Node 타입 선언 또는 같은 플랫폼 타입을 제공하는 환경이 필요합니다. 특정 홈 디렉터리나 결과 라이브러리는 요구하지 않습니다. 설치와 첫 명령 작성은 [시작하기](getting-started.md)를 참고합니다.
